# EdgeScan Research

Public cybersecurity research and technical investigations published by **BCC Risk Advisory**.

This repository brings together research papers, vulnerability analyses, and practical security investigations. Each research topic has its own directory with the relevant write-ups, references, and supporting material.

## Repository Organisation

Each top-level research directory is self-contained. A directory may contain a full paper, individual case studies, figures, or technical notes, depending on the investigation.

There is no requirement to run scripts to read the findings.

## Research Notes

Findings reflect the information available at the time of each investigation. Where relevant, individual publications describe their methods, evidence, limitations, and any use of AI-assisted tools.

A CVE's rejection status alone does not establish that the underlying vulnerability claim was false.

## Responsible Use

Materials are provided for research, education, and defensive security analysis. Review the scope, limitations, and disclosure status of each investigation before reproducing any tests.
